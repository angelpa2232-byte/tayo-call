# 타요 무료 로컬 AI 영상통화

기본 대화 AI는 **Qwen3.5 9B**, 실행 도구는 Ollama입니다. API 키나 유료 API를 사용하지 않습니다. 음성인식은 로컬 Whisper tiny, 음성 출력은 Windows 한국어 오프라인 음성입니다. 타요는 움직이는 SVG 캐릭터이며 원작 성우 음성은 아닙니다.

## 현재 PC와 모델
확인된 PC: i7-1165G7(4코어), RAM 약 16GB, GTX 1650 Ti 4GB.
9B와 14B를 실제 동일한 공룡·타요 질문으로 비교하고, 9B에서 과일·주제 변경까지 이어서 시험했습니다. 해당 비교에서는 9B가 문장 연결과 역할 유지에서 상대적으로 나아 기본으로 선택했습니다. 이는 모든 무료 모델의 절대 순위나 GPT 수준의 품질을 보장한다는 의미는 아닙니다.

- 기본: `qwen3.5:9b` (다운로드 약 6.6~7.6GB)
- 비교 옵션: `qwen3:14b` (약 9.3GB)
- 빠른 옵션: `qwen3:4b-instruct-2507-q4_K_M`
- 기존 경량 옵션: 1.7B, 0.6B

설정에서 모델을 선택할 수 있습니다. 9B와 14B는 이 프로젝트 폴더에 설치됐습니다. 첫 새로고침은 기존 설정을 9B 기본값으로 전환하고, 이후 선택한 모델은 유지합니다.

9B 시험에서 첫 로딩 포함 약 35초, 이후 답변 약 9~16초가 걸렸습니다. 14B는 첫 답변 약 58초, 이후 약 16~17초였으며 타요 역할을 잘못 해석하는 사례가 있었습니다. 실제 음성 통화에서는 음성인식 시간이 추가됩니다. 9B도 엉뚱한 사실과 어색한 표현이 나올 수 있어 부모님이 함께 사용해야 합니다.

## 실행
1. `타요영상통화_시작.bat` 실행 (이미 실행 중이면 이전 서버 창을 종료한 후 실행).
2. http://127.0.0.1:8088/ 접속. 브라우저가 서버보다 먼저 열렸으면 새로고침.
3. 부모님 설정에서 별명, 모델, 한국어 목소리, 놀이 시간 지정.
4. 통화 받기 → 카메라·마이크 권한 허용.
5. 아이가 말하고 약 1.5초 조용해지면 음성인식 → AI 답변 → 음성 읽기 순서로 처리합니다.
6. 음성인식 오류는 화면의 '인식된 말'로 확인하고, 하단 글자 입력으로 대신 대화할 수 있습니다.
7. 통화 종료는 녹음·카메라·진행 중인 답변·음성 재생을 중지합니다. 서버 실행 창은 Ctrl+C로 종료합니다.

Ollama 백그라운드 서버는 남고 모델은 마지막 요청 이후 약 1분 뒤 메모리에서 내려갑니다. 한국어 목소리가 없다면 Windows 설정 → 시간 및 언어 → 음성에서 한국어 음성을 설치하고 브라우저를 재시작하세요.

## 처음 준비 또는 다른 PC
`Ollama_준비.bat` 실행. Node.js 22 이상과 Python 3.10 이상을 권장하며, 이 PC의 Codex 번들 런타임도 자동으로 찾습니다. 최초 다운로드에는 인터넷과 충분한 디스크 공간이 필요합니다. 공식 Ollama 포터블, 9B 모델, Python 음성인식 패키지와 Whisper 모델을 프로젝트 폴더에 준비합니다. 모델 준비 후 대화는 로컬에서 처리합니다. RAM 4GB에서는 9B 모델을 권장하지 않습니다.

## 대화와 데이터
최근 6회 왕복 대화와 4096 토큰 문맥을 사용합니다. 두 번 대화하면 주제를 강제로 바꾸거나 질문을 고정 문장으로 대체하는 처리는 제거했습니다. 아이의 질문에 답하고 관련 주제를 자연스럽게 이어가도록 모델에 요청합니다.
웹캠은 내 화면에만 표시하며 AI로 보내지 않습니다. 녹음은 로컬 서버와 Python 메모리에서 처리하고 앱은 음성·영상·대화 기록을 파일에 저장하지 않습니다. 별명·목소리·모델·놀이 시간만 브라우저에 저장합니다. Ollama 자체의 운영 로그는 별도입니다.

## 아이가 참여하는 상상 이야기
통화 시작은 로기의 작은 고장을 돕는 상상 놀이입니다. 로기 고장 → 선물 배달 → 공룡 공원 → 세차의 짧은 장면을 순환합니다. 아이의 응/아니, 이름, 의성어도 답으로 받아 다음 장면으로 이어가게 합니다. 정비는 어른 정비사가 하고, 아이에게 실제 차량이나 기계를 만지게 하지 않습니다.
타요가 말한 뒤 18초간 조용하면 현재 장면을 쉽게 다시 제안합니다. 침묵 중에는 아이가 답한 것처럼 대화 기록에 넣지 않으며 장면도 넘어가지 않습니다. 연속 침묵에는 최대 두 번만 말을 걸고 기다립니다. 아이가 대답하면 말걸기 횟수를 초기화합니다. 마이크 음소거, 설정 창, 숨겨진 화면, 종료 중에는 자동 말걸기를 멈추거나 미룹니다. 기존 놀이 시간 제한은 유지합니다.
검증: `node proactive-ui.test.mjs`, `node story-smoke.mjs`.

## 말투와 목소리 개선
기본 음성 엔진은 Windows TTS에서 로컬 Supertonic-3 한국어 신경망 음성으로 변경했습니다. 부모님 설정에서 남성 M1/M2/M3, 여성 F3를 선택하거나 Windows 기본 음성으로 돌아갈 수 있습니다. 기본은 M3이며 원작 성우 복제 음성은 아닙니다. Supertonic 오류가 나면 Windows 음성으로 대체하며 상태 문구에 표시합니다.
대사는 짧은 구어체로 생성하도록 보강했고, 첫 인사의 긴 기술 소개는 화면의 AI 놀이 표시와 부모님 안내로 옮겼습니다. 질문하면 AI라는 점을 알려주는 지침은 유지합니다. 신경망 음성은 출력 음량에 맞춰 입이 움직입니다.
모델 설치와 WAV 생성, TTS 경로, 통화 종료 후 지연 음성 재생 방지를 검증했습니다. `runtime/tayo-voice-sample.wav`는 인위적으로 만든 테스트 대사 샘플이며 아이 녹음 파일이 아닙니다. 새로운 음성이 사용자에게 더 자연스럽게 들리는지는 실제 청취로 확인해야 합니다.
공식 사용 안내: https://github.com/supertone-inc/supertonic-py

## 원작 그림과 캐릭터 전환
타요·로기·라니·가니·프랭크·패트 원작 그림을 연결했습니다. "프랭크", "프랭크랑 얘기하고 싶어"처럼 상대를 선택하면 화면, 합성 목소리, AI 역할이 함께 바뀝니다. 이름 버튼으로도 선택 가능합니다. 등장, 차체 흔들림, 음량에 맞춘 입 움직임, 눈 깜빡임, 출발 모션과 경광등 효과를 적용했습니다. 원작 3D 애니메이션이나 원작 성우 음성은 아닙니다.
그림 출처: https://iconix.co.kr/works/iconix-detail.php?idx=2 (©SEOUL/ICONIX/EBS).
`?preview=frank`는 장치 없이 캐릭터를 비교하는 미리보기이며 실제 통화는 기본 주소에서 시작합니다.

## 상황에 맞는 장면 그림
프랭크의 소방 놀이에는 소방서 출동, 불 모형이 켜진 훈련장, 움직이는 물줄기, 진화 완료의 4개 그림 상태를 연결했습니다. 프랭크 원작 캐릭터 PNG와 새로 만든 SVG 배경·소품이 함께 표시됩니다. 실제 화재나 부상 장면이 아닌 유아용 상상 놀이입니다. 차고지/공구, 선물/친구 집, 공룡 모형, 세차 거품도 각 상황에 표시합니다.
서버가 대사를 만든 현재 장면을 visual 필드로 반환하고, 다음 응답에 사용할 이야기 상태와 별도로 유지해 화면이 대사보다 한 장면 앞서가지 않도록 했습니다. 미리보기는 `?preview=frank&step=0`부터 `step=3`까지 확인할 수 있습니다.
검증: `node --test scene-visuals.test.mjs`.

## OpenAI 대화 연결
부모님 설정에서 대화 방식을 OpenAI API로 고르고 키를 입력해 저장합니다. 키 권한 확인 후 서버의 runtime/openai-settings.json에 저장하며 브라우저에는 저장하지 않습니다. 이 파일은 비밀 키를 포함하므로 공유하지 마세요. runtime은 Git 제외 대상이며 HTTP로 접근할 수 없습니다. 모델은 GPT-5.4 mini, 추론 none, 짧은 텍스트 응답을 사용합니다. 실제 API 답변은 과금되며 인식된 말과 최근 대화 및 놀이 프롬프트가 전송됩니다. 카메라와 녹음은 전송하지 않습니다. 음성인식/합성은 로컬 방식을 유지합니다. Responses store:false는 대화 저장을 끄는 설정이며 OpenAI의 별도 데이터 정책을 대체하지 않습니다. 로컬 대화로 돌아갈 때는 Ollama를 선택하세요. 키 검증은 모델 조회이며 실제 생성 테스트는 첫 통화에서 수행합니다.

## 캐릭터별 OpenAI 음성
음성 엔진 OpenAI를 선택하면 API 키를 서버에서 사용해 /v1/audio/speech로 답변을 읽습니다. 각 캐릭터는 다른 기본 음성과 한국어 표현 지시를 사용하며 원작 성우 복제가 아닙니다. 음성 사용료가 추가되고 답변 텍스트가 전송됩니다. 재생 오류/키 오류는 Windows 예비 음성으로 읽습니다. 호출 취소와 통화 종료 후 지연된 음성 재생을 방지합니다. 현재 Speech API 문서에 명시된 gpt-4o-mini-tts 모델을 사용하며, 공식 종료 예정일 2027-01-06 전에 Realtime 방식으로 이전이 필요합니다.

## 행동이 보이는 상황 놀이
프랭크 소방 출동과 패트 도로 수습, 로기 정비, 고양이 인형 구조에는 캐릭터 PNG와 단계별 SVG 장면을 사용합니다. 얼굴은 작은 화면으로 줄이고 현장을 크게 표시합니다. 출동 요청은 즉시 사건을 시작합니다. 사건 안내 음성이 끝난 뒤 3초 동안 아이 발화를 기다리고, 말이 없으면 다음 장면을 이어갑니다. 주요 장면 안내는 화면과 일치하는 작성된 대사를 사용하고 질문에는 AI가 답합니다. 설정 열기, 음소거, 화면 숨김, 아이 발화 중에는 진행을 기다리며 종료 시 진행 예약을 취소합니다. 일반 대화 중에는 기존 대화와 관심사 흐름을 유지합니다. 3D 영상이 아닌 2D 이미지·SVG 애니메이션입니다.

## 캐릭터별 5개 상황극 (총 30개)
- tayo: 승객 나들이, 공룡 공원, 굴러온 공, 비 오는 나들이, 공사 길 우회 운행
- rogi: 작은 고장, 숨바꼭질, 공 돌려주기, 소풍 준비, 진흙길 탈출
- lani: 선물 배달, 인형 찾기, 꽃밭 소풍, 빗속 정류장, 나무에 걸린 풍선
- gani: 거품 세차, 간식 꾸러미, 별 구경, 친구 소풍, 놀이터 청소
- frank: 프랭크 소방 출동, 고양이 인형 구조, 소방서 구경, 물 표적 놀이, 도로의 가지 치우기
- pat: 신호등 순찰, 길 안내, 도로 사고 수습, 공 주인 찾기, 횡단보도 길 안내
각 상황은 4단계 대사와 SVG/PNG 그림을 갖습니다. 장면 진행 음성이 끝난 뒤 자동으로 다음 행동을 이어가며, 이야기로 돌아온 뒤에는 다른 상황으로 순환합니다. “진흙길 탈출 보여줘”, “꽃밭 소풍 가자”처럼 상황 이름과 실행 요청을 말하면 바로 시작합니다.

## 조용한 아이를 위한 대화 진행
말이 없으면 안내 종료 약 9초 뒤 다시 말을 걸고 이후 12~16초씩 기다립니다. 두 번 후 멈추는 제한은 제거했습니다. 음식/장난감/동물 선택 질문, 캐릭터 자신의 놀이 이야기, 그림 상황극, 지난번 쉬는 날 한 놀이 질문을 순환합니다. 아이의 대답을 지어내지 않으며 진행 신호는 아이 발언으로 기록하지 않습니다. 사건은 자동 진행하고 다시 일상 이야기로 돌아옵니다. 통화 시간 제한, 음소거, 설정 및 화면 숨김/종료에 따른 대기는 유지합니다.

## 시작 파일
상위 폴더의 타요영상통화_시작.bat 또는 tayo-call/start.bat를 더블클릭합니다. launch.ps1이 서버를 숨김 상태로 실행하고 정상 HTTP 응답을 확인한 뒤 브라우저를 엽니다. 이미 실행 중이면 기존 서버를 사용합니다. 시작 명령창이 닫혀도 서버는 유지됩니다. 실패 시 오류를 표시하고 runtime/server-start-error.log에 서버 기록을 남깁니다. 테스트나 브라우저를 열지 않는 실행은 -NoBrowser 옵션을 사용할 수 있습니다.

## 프로그램 완전 종료

## 음성인식 없이 하는 상황극 (기본 모드)
부모님 설정의 “아이 음성인식”에서 끄기/켜기를 저장합니다. 기본은 끄기이며, 꺼져 있으면 마이크 권한 요청·녹음·음성인식 API 호출을 하지 않습니다. 카메라는 별도로 동작합니다. 캐릭터가 먼저 놀이를 소개하고, 말이 완전히 끝난 뒤 5초를 기다렸다가 다음 장면을 이어갑니다. 대답이 없어도 멈추지 않고 아이가 답했다고 지어내지 않습니다. 네 번째 장면 후에도 다음 상황극으로 이어갑니다. 캐릭터는 화면 이름 버튼이나 부모님 글자 입력으로 변경할 수 있습니다. 통화 중 설정을 바꿔도 적용하며, 음성인식을 끄면 사용 중인 마이크 트랙을 해제합니다. 설정 창과 다른 화면을 보고 있을 때는 진행을 기다리고, 통화/프로그램 종료 시 예약과 요청을 취소합니다.

“새 상황극 만들기”를 켜면 선택한 대화 AI(OpenAI 또는 Ollama)가 캐릭터에게 가능한 서로 다른 사건 두 개를 엮어 제목·연결 대사를 생성하고, 현재 행동에 맞는 참여 제안을 고릅니다. 사건의 실제 행동 대사는 화면과 맞는 기본 대사를 사용합니다. 이야기 한 편은 2개 사건×4단계이며, 다음 편을 만들 때 최근 제목을 보내 반복을 줄입니다. 각 장면은 해당 사건의 기존 배경·물체·애니메이션으로 재생합니다. 임의의 새로운 그림/3D 영상을 생성하는 기능은 아닙니다. 화면에 없는 행동을 지어내지 않도록 사용 가능한 장면으로 생성 형식을 제한하고 검사합니다. 연결/형식 검증 실패 시 기본 상황극으로 대체하며 화면에 표시합니다. 새 이야기 생성 시 추가 준비 시간이 있을 수 있습니다.
새 이야기 끄기는 준비된 다섯 상황극을 차례로 반복하며 대화 모델을 호출하지 않습니다(선택한 음성 엔진의 호출은 별도). OpenAI로 새 이야기를 만들면 텍스트 생성 요금이 발생하고, OpenAI 음성을 선택하면 음성 요금도 발생합니다. 키는 서버에 유지합니다. 새 이야기 기본값은 켜기이며 부모님이 끌 수 있습니다.
구조화 형식 참고: https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses 및 https://docs.ollama.com/capabilities/structured-outputs


## 배경 표지판과 캐릭터 즉시 변경
배경 건축 레이어의 중복 간판을 제거해 이름은 전경 건물/표지판에서만 표시합니다. 캐릭터 선택 버튼은 상황극·음성 생성·낭독·노래 중에도 누를 수 있습니다. 선택하면 이전 요청과 재생을 취소하고 그림/역할을 먼저 바꾼 뒤 선택한 캐릭터 인사를 읽습니다. 통화와 카메라는 유지합니다. 이전 요청이 늦게 도착하거나 이전 음성 종료 이벤트가 나중에 발생해도 새 캐릭터를 덮어쓰지 않도록 별도 작업 번호로 검사합니다. 버튼은 노래 화면 위에서도 사용할 수 있습니다.

시작 화면의 🐬 해양동물 알아보기 또는 통화 중 🐬 바다동물 버튼으로 들어갑니다. 돌고래·고래·범고래·상어·흰동가리·블루탱·해마·가오리·복어·문어·오징어·해파리·바다거북·펭귄·물범·바다코끼리·해달·게·불가사리·새우 20종을 제공합니다. 동물 그림, 서식 배경, 움직임과 세 장의 짧은 설명을 로컬에 포함합니다.

부모님 설정의 음성인식이 꺼져 있으면 그림 선택만 사용하며 마이크를 요청하지 않습니다. 켜져 있으면 안내나 설명을 읽은 뒤 동물 이름을 듣습니다. 말소리가 없으면 12초 뒤 녹음을 끝내며 음성인식 요청은 보내지 않습니다. 다시 말하려면 이름 말하기 버튼을 누릅니다. 소리가 감지되면 약 1.1초의 말 끝 쉼을 기다린 뒤 로컬 Whisper로 이름을 인식합니다. 인식용 어휘는 해양동물 이름을 우선하도록 별도로 전달합니다.

돌고래와 고래, 범고래를 구분하고 니모·도리·거북이·돌고레·무너·팽귄 등 일부 다른 이름과 발음도 받아들입니다. 다음 설명·다시 들려줘·다음 동물·그림 목록 같은 명령도 사용할 수 있습니다. 부정확한 발음이 항상 인식되는 것은 아니며 인식 실패 시 그림 선택을 계속 사용할 수 있습니다.

이름 인식은 외부 대화 AI를 호출하지 않습니다. 녹음은 메모리에서 처리하며 별도 파일로 저장하지 않습니다. 동물 선택·다른 메뉴 전환·닫기·완전 종료 시 녹음, 마이크와 인식 요청을 정리하고 늦게 도착한 결과를 무시합니다. 통화 중 설명을 OpenAI 음성으로 읽도록 설정했다면 읽어주기 음성 요금은 발생할 수 있습니다.
