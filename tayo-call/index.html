설정 (부모님용 안내)

Ollama 무료 로컬 AI · 3세용 짧은 대화입니다. 작은 모델은 엉뚱한 답을 할 수 있으니 부모님이 함께 사용해주세요.

키는 이 PC의 서버에 저장됩니다. 저장 후 입력칸은 비워집니다.

OpenAI 선택 시 인식된 말과 최근 대화, 놀이 설정을 OpenAI로 보내며 API 사용료가 발생합니다. 카메라와 녹음 원본은 전송하지 않습니다. 저장하기에서 키 권한을 확인하며, 이 확인은 대화를 생성하지 않습니다.

끄면 마이크를 사용하지 않습니다. 캐릭터가 말한 뒤 5초 기다렸다가 다음 장면을 계속합니다. 아이는 소리나 몸짓으로 자유롭게 참여해도 됩니다.
음성인식이 꺼진 상황극 모드에서 적용됩니다. AI는 준비된 배경과 동작을 조합해 새 이야기를 만듭니다. OpenAI 선택 시 생성 요금이 발생하며, 연결 실패 시 기본 상황극을 이어갑니다.
대화 AI와 별도로 선택합니다.
목소리가 없으면 Windows 설정 → 시간 및 언어 → 음성에서 한국어 음성을 설치해주세요.
Ollama를 선택했을 때만 사용하는 모델입니다.

OpenAI 음성은 타요·로기·라니·가니·프랭크·패트마다 목소리와 억양이 바뀝니다. 원작 성우가 아닌 AI 합성 목소리이며 답변 문장을 음성 API로 전송합니다. 음성 사용료가 추가됩니다.

처음에는 상위 폴더의 Ollama_준비.bat를 실행해주세요. 모델 다운로드에는 인터넷과 여유 디스크 공간이 필요합니다.

음성인식은 이 PC에서 실행합니다. 목소리는 선택한 음성 엔진에서 생성합니다. 웹캠은 화면에만 표시하고 녹음 원본은 파일에 저장하지 않습니다. 원작 성우 음성이 아닌 로컬 합성 목소리를 사용합니다.
